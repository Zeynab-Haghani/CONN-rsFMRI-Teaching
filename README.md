# Resting-State fMRI Analysis Using the CONN Toolbox

### Educational Materials | Sessions 04–05

**Instructor: Zeynab Haghani**

Welcome to my educational repository dedicated to resting-state functional MRI (rs-fMRI) analysis using the **CONN Toolbox**.

This repository documents two teaching sessions covering three complementary approaches to investigating functional brain connectivity and network organization.

## Course Sessions

### Session 04 | ROI-to-ROI Functional Connectivity & Graph Measures

**ROI-to-ROI Analysis**
- Understanding functional connectivity between brain regions
- Exploring connectivity matrices and connectome visualizations
- Performing second-level group comparisons
- Interpreting statistical contrasts and connectivity results

**Graph Theory & Network Measures**
- Understanding brain networks as nodes and edges
- Exploring graph-theoretical measures in CONN
- Understanding connectivity thresholds
- Interpreting network organization and graph analysis results

### Session 05 | Group Independent Component Analysis (ICA)

- Introduction to data-driven resting-state network identification
- Performing Group ICA in CONN
- Understanding spatial maps and component time series
- Matching components to reference network templates
- Exploring spatial and temporal component measures
- Interpreting second-level statistical results

## Software and Tools

- CONN Toolbox
- MATLAB
- SPM
- Resting-state fMRI data

## Educational Objectives

The goal of these sessions was to connect theoretical concepts in functional neuroimaging with hands-on analysis, critical thinking, and scientifically responsible interpretation of results.
