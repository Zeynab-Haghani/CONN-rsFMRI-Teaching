# Resting-State fMRI Analysis Using the CONN Toolbox

### Educational Materials | Sessions 04–06

**Instructor: Zeynab Haghani**

Welcome to my educational repository dedicated to resting-state functional MRI (rs-fMRI) connectivity analysis using the **CONN Toolbox**.

This repository documents three sessions I taught, focusing on practical neuroimaging workflows, functional brain connectivity, network analysis, and data-driven identification of resting-state networks.

## Course Sessions

### Session 04 | ROI-to-ROI Functional Connectivity

- Understanding functional connectivity between brain regions
- Exploring ROI-to-ROI connectivity matrices and connectome visualizations
- Performing second-level group comparisons
- Interpreting statistical contrasts and connectivity results

### Session 05 | Graph Theory and Network Measures

- Understanding brain networks as nodes and edges
- Introduction to graph-theoretical analysis
- Exploring network measures in CONN
- Understanding connectivity thresholds and network organization
- Interpreting graph analysis results

### Session 06 | Group Independent Component Analysis (ICA)

- Introduction to data-driven resting-state network identification
- Performing Group ICA in CONN
- Understanding spatial maps and component time series
- Spatial matching to reference network templates
- Exploring spatial and temporal component measures
- Interpreting group-level statistical results

## Software and Tools

- CONN Toolbox
- MATLAB
- SPM
- Resting-state fMRI datasets

## Educational Objectives

The main objective of these sessions was to bridge theoretical concepts in functional neuroimaging with hands-on analysis and scientifically responsible interpretation of results.
